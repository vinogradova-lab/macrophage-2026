## Whole Proteome Analysis

Proteins were required to be quantified in at least two replicates (out of four).

Channel ratios (signal intensity / sum of signal intensities per protein) were calculated witihin each replicate and used for all analyses.

**Principal component analysis (PCA)** was performed using scikit-learn (Pedregosa et al., 2011) library for Python. Channel ratio values were log2 transformed and only proteins quantified in all experiments were used. PC1 and PC2 were plotted. Loadings for plotting were selected by taking the 20 proteins with highest and lowest loadings for both PC1 and PC2. 

**Volcano plots**: p-values were calculated with T-test for the means of two independent samples and volcano plots show −log10 p-values on y axis and log2 fold change on x axis. Significant proteins (< 0.05, -log10(0.05) = 1.3) which show a > 1.5 fold change are highlighted.

A hierarchically-clustered **heatmap** of top proteins is provided as pdf (can be searched cmd+F) and can be compared to volcano plots. The heatmap shows the top 30 significantly up and down regulated proteins for all conditions and uses the channel ratio values to calculate a z score.

**GOterm analysis** with significant up/down/up and down regulated proteins - implemented in Python using goatools

Each file folder has a separate goterm_analysis folder which holds the plots and tables. The names of the files follow this scheme:

goterm_BACKGROUND_CONDITION _DOWN/UP/DOWN&UP_go_term_plot.csv or pdf

More details: GOEA analysis was performed on the significant up or down or up & down regulated proteins (mapped to gene IDs using gProfiler). Enriched ontologies with a Benjamini-Hochberg-corrected p-value less than 0.05 were retained and top 10 terms were plotted. Corresponding tables which also show the names of the genes for each term are also provided Some plots are empty which means that nothing passed the Benjamini-Hochberg-corrected p-value 0.05 threshold.

[go-basic.obo](https://geneontology.org/docs/download-ontology/) was used, downloaded on October 16, 2024. 

**Whole proteome vs RNA** plots were generated by merging RNA differential expression results ('Macrophage project/RNA-seq/RNA-seq_Beatrice/macrophage_analysis/DEG') with proteomics results on UniProt or gene name. Quadrants were labeled using a FC cutoff of 1.5 for both WP and RNA results. Whole proteome fold change was calculated based off the mean of replicates. Results were not filtered based on p-value.

## Reference list creation

The basic gene ontology, [go-basic.obo](https://geneontology.org/docs/download-ontology/) downloaded on June 20, 2023, was queried using [GOATOOLS v1.2.3](https://github.com/tanghaibao/goatools) to create reference gene lists describing biological pathways.

GO terms fields (title, definition, and synonyms) were queried for substrings related to biological pathways.
